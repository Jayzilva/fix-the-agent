 # learn-adr

Simple repository for experimenting with Architecture Decision Records (ADRs).

## Getting Started

- Clone this repository
- Open it in your editor of choice
- Explore the ADR examples and structure

## ADRs

Architecture Decision Records are short documents that capture important
engineering decisions, along with their context and consequences.

Use this repo to practice:

- Writing new ADRs
- Updating existing decisions
- Reviewing and discussing trade-offs
