# Compute-hour overage charges

Article ID: KB-010 | Category: billing | Last updated: 2026-08-25

## Summary

Each plan includes a monthly compute-hour allowance; usage beyond it is billed at the overage rate. Billing > Usage shows hourly usage per project so you can trace the spike.

## Symptoms

You may see this when we got a large overage charge for compute hours that we don't think we used.

## Common question

Customers often ask how are compute-hour overages calculated.

## Resolution

1. Each plan includes a monthly compute-hour allowance; usage beyond it is billed at the overage rate.

2. Billing > Usage shows hourly usage per project so you can trace the spike.
