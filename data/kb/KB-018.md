# API rate limits and 429 errors

Article ID: KB-018 | Category: technical | Last updated: 2026-08-07

## Summary

The API allows 600 requests per minute per token on Pro and 3,000 on Enterprise. Honour the Retry-After header and use exponential backoff on 429 responses.

## Symptoms

You may see this when our integration is getting HTTP 429 Too Many Requests errors from the API.

## Common question

Customers often ask what are the API rate limits for our plan.

## Resolution

1. The API allows 600 requests per minute per token on Pro and 3,000 on Enterprise.

2. Honour the Retry-After header and use exponential backoff on 429 responses.
