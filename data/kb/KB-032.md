# Memory limit exceeded (OOMKilled)

Article ID: KB-032 | Category: technical | Last updated: 2026-08-14

## Summary

OOMKilled means the process exceeded the instance memory. Raise the instance size or set the runtime's heap limit below the container limit.

## Symptoms

You may see this when our containers keep restarting with the status OOMKilled.

## Common question

Customers often ask how do I choose the memory size for a service.

## Resolution

1. OOMKilled means the process exceeded the instance memory.

2. Raise the instance size or set the runtime's heap limit below the container limit.
