# Static site returns 404 after deploy

Article ID: KB-042 | Category: technical | Last updated: 2026-08-09

## Summary

Set the output directory correctly and add a rewrite rule from /* to /index.html for single-page apps under Project > Routing.

## Symptoms

You may see this when our static site returns 404 for every page except the homepage after the last deploy.

## Common question

Customers often ask how do I configure routing for a single-page app.

## Resolution

1. Set the output directory correctly and add a rewrite rule from /* to /index.html for single-page apps under Project > Routing.
