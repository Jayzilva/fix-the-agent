# High latency in eu-west

Article ID: KB-029 | Category: technical | Last updated: 2026-08-07

## Summary

Check the per-region latency dashboard and the status page. Enable the edge cache for static routes and place the database in the same region as the service.

## Symptoms

You may see this when response times in eu-west jumped from 80ms to over 2 seconds.

## Common question

Customers often ask how can we reduce latency for users in Europe.

## Resolution

1. Check the per-region latency dashboard and the status page.

2. Enable the edge cache for static routes and place the database in the same region as the service.
