# Personal access tokens expiring

Article ID: KB-056 | Category: account | Last updated: 2026-08-09

## Summary

Personal access tokens expire after 90 days by default. Create a new token under Profile > Tokens, or use a service account token for automation.

## Symptoms

You may see this when our personal access token suddenly stopped working with an 'expired token' error.

## Common question

Customers often ask how long do personal access tokens last.

## Resolution

1. Personal access tokens expire after 90 days by default.

2. Create a new token under Profile > Tokens, or use a service account token for automation.
