# CLI install and 'nimbus: command not found'

Article ID: KB-023 | Category: technical | Last updated: 2026-08-05

## Summary

Install with the official installer, then add ~/.nimbus/bin to your PATH and open a new terminal. Run 'nimbus version' to confirm.

## Symptoms

You may see this when after installing the CLI the terminal says 'nimbus: command not found'.

## Common question

Customers often ask how do I install the Nimbus CLI.

## Resolution

1. Install with the official installer, then add ~/.nimbus/bin to your PATH and open a new terminal.

2. Run 'nimbus version' to confirm.
