# GitHub integration not triggering builds

Article ID: KB-034 | Category: technical | Last updated: 2026-08-28

## Summary

Reinstall the Nimbus GitHub App and confirm it has access to the repository. Builds trigger only for the branch set in Project > Git > Production branch.

## Symptoms

You may see this when pushing to our main branch no longer triggers builds from the GitHub integration.

## Common question

Customers often ask how does the GitHub integration trigger builds.

## Resolution

1. Reinstall the Nimbus GitHub App and confirm it has access to the repository.

2. Builds trigger only for the branch set in Project > Git > Production branch.
