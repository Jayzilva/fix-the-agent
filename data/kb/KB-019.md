# Rotating API keys

Article ID: KB-019 | Category: technical | Last updated: 2026-08-03

## Summary

Create the new key first, deploy it everywhere, then revoke the old key. Revoked keys stop working immediately; there is no grace period.

## Symptoms

You may see this when after rotating our API key all requests started failing.

## Common question

Customers often ask what is the recommended way to rotate API keys.

## Resolution

1. Create the new key first, deploy it everywhere, then revoke the old key.

2. Revoked keys stop working immediately; there is no grace period.
