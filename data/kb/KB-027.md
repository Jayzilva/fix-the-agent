# Environment variables not applied after deploy

Article ID: KB-027 | Category: technical | Last updated: 2026-08-16

## Summary

Environment variable changes apply only to new deployments. Trigger a redeploy (or a restart) after saving the variables.

## Symptoms

You may see this when we changed an environment variable but the running app still uses the old value.

## Common question

Customers often ask do environment variable changes need a redeploy.

## Resolution

1. Environment variable changes apply only to new deployments.

2. Trigger a redeploy (or a restart) after saving the variables.
